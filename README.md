# Practice Projects

This repository contains C# practice projects and the main project.

## Git Workflow

The Git workflow used for this repository:

1. Check the current repository status:
   ```bash
   git status
   ```

2. Add the changes:
   ```bash
   git add .
   ```

3. Commit the changes using the requirement ID:
   ```bash
   git commit -m "CL1: add list practice"
   ```

4. Push the changes to GitHub:
   ```bash
   git push
   ```

5. Pull changes made from GitHub or another clone:
   ```bash
   git pull
   ```

6. Check the commit history:
   ```bash
   git log --oneline
   ```
