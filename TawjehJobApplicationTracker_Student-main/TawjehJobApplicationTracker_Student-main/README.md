# Job Application Tracker — Student Project

A small C# Console Application for practicing requirement analysis, C# collections, and generics.

## Requirements
- .NET 8 SDK or a compatible newer SDK.

## Run
From this folder:

```bash
dotnet run
```

## Workshop flow
1. Read a requirement in `Requirements/WorkshopRequirements.md`.
2. Identify its actor, inputs, output, validations, and business rules.
3. Write Given/When/Then acceptance criteria.
4. Choose a suitable collection and explain why.
5. Implement the TODO in the matching file under `Features`.
6. Run the program and test normal and edge cases.

## Features to implement
- Find a job by ID.
- List companies by status.
- Apply to a job.
- Check candidate email availability.

The project is intentionally simple: no database, web framework, or external packages.
